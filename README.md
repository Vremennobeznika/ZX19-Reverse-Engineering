# ZX19 / R19Z

Собственная прошивка для часов ZX19 в разработке. Для просмотра интерфейса скачайте `ZX19-preview.html` и откройте в браузере. Готового образа для установки пока нет.

В репозитории — исходники, инструменты сборки и тесты. В полном рабочем каталоге до публикации прошли 64 теста на компьютере. Часть исследовательских проверок требует отдельных входных данных, включая штатный OTA `R19Z_1.00.18_241125.bin`.
