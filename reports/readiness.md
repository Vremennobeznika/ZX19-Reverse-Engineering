При подключении по Bluetooth 18 ноября 2026 часы вернули аппаратную версию R19Z_V1.0 и версию приложения R19Z_1.00.18_241125. Это совпадает с исследованным OTA. Собственный код готовит шину и выводы, включает H_0 и запускает панель. Стенд моделирует регистры, ROM и показания времени. В едином ELF обработчики подготавливают таблицу векторов, регистрируют задачу дисплея и вызывают планировщик. В интеграционном испытании стенд выполняет вызовы зарегистрированных обработчиков, имитирует ROM и планировщик; обработчик Bluetooth-стека подменён. Циферблат показывает прочерки до получения времени. Сборка регистрирует сервис записи времени через GAP из SDK. Тест на ARM вызывает зарегистрированный обработчик, проверяет переход на 29 февраля и перенос счётчика миллисекунд. Chrome проверен с имитацией GATT. После перезапуска время нужно установить заново. Реальное сопряжение, передача времени по радио и повторная прошивка из нового приложения остаются открыты. Сравнение локального OTA с тремя библиотеками gap_utils из SDK ART-Badge (ревизия 116b2296) дало 52 точных совпадения функций длиной от 12 байт у каждой библиотеки. Ни одно совпадение не отличает её от обеих других. Версия стека на устройстве этим методом не определяется. Независимый от исполняемого приложения канал восстановления на данном экземпляре не подтверждён.

Для синхронизации с собственной сборкой предназначен [ZX19-time.html](../ZX19-time.html). Страница выбирает устройство с именем «ZX19 Libre» и ожидает подтверждение записи. На штатной прошивке это имя не объявляется. При первой сборке инструменты загружают заголовки и библиотеку GAP из фиксированной ревизии SDK. Офлайн-сборка использует локальный кэш.

## Воспроизведение

В полном рабочем каталоге Windows с подготовленными зависимостями проверки запускаются следующими командами. Для части исследовательских тестов требуется исходный заводской OTA.

```powershell
.\tools\python\python.exe tools/build_core.py
.\tools\python\python.exe -m unittest discover -s tests
.\tools\python\python.exe tools/test_r19z_startup.py
.\tools\python\python.exe tools/test_r19z_panel.py
.\tools\python\python.exe tools/test_r19z_i2c.py
```

## Образ приложения 0.1.0-dev

[Скачать 17 692 байта для ZX19 R19Z_V1.0](../firmware/ZX19-Libre-0.1.0-dev-R19Z_V1.0.bin). SHA-256 файла — 455b9b248bcdde5ebaf850c7b3a72d8f9659b68a34fde517ebc3007213f6e0f4.

Образ заменяет приложение часов и использует существующие ROM и Bluetooth-стек. В приложении есть циферблат, сенсорное меню, таймер, секундомер и установка времени. Передача уведомлений с телефона, физическая кнопка и повторное OTA из этой версии ещё не реализованы. При неудачном запуске Bluetooth может оказаться недоступен для возврата штатного приложения.

Сборка выполняется командой `tools\python\python.exe tools\package_r19z.py`. Полезная нагрузка побайтно совпала с результатом Zig objcopy. Утилита SDK независимо воспроизвела контрольную сумму. Команда `tools\python\python.exe tools\test_r19z_panel.py firmware\ZX19-Libre-0.1.0-dev-R19Z_V1.0.bin` выполнила 15 сценариев на эмуляторе Cortex-M4. В трёх сценариях старта эмулятор загрузил память из OTA. Физическая установка, восстановление и расход аккумулятора в этой версии не проверялись.
